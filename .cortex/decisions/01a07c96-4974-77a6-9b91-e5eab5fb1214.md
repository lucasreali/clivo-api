AuditTrailController and AuditEntryView moved from core/billing/internal to common/audit/internal. The audit trail is not a billing concern; it sat there only because billing was where management data was already exposed, which made core/billing the accidental owner of a cross-cutting read.

common/audit already owns the domain types (AuditEntry, AuditTrail, AuditedRecord, AuditEntrySnapshot) and the AuditLogRepository in its internal package, so the controller is now next to the code it reads. common is an OPEN Spring Modulith module and already hosts web concerns (ApiExceptionHandler, ModuleGuardConfiguration), so no boundary was widened and no new application module was created. The endpoint, its path (/api/audit-trail), tag and operationId (getAuditTrail) are unchanged, so the published OpenAPI contract is identical.
